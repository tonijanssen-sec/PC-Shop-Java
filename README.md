# PC-Shop Java

Java OOP Schulprojekt – Produktverwaltungssystem für einen PC-Shop.  
Entwickelt im Rahmen der Ausbildung zum Fachinformatiker Systemintegration.  
Note: 1.0 (98/100 Punkten)

## Funktionen
- Produkte anlegen (Monitor, Motherboard, Tastatur, Maus)
- Produkte anzeigen und bearbeiten
- Produktliste verwalten

## Klassenstruktur
- `Produkt` – Basisklasse mit Marke, Modell, Preis
- `Monitor`, `Motherboard`, `Tastatur`, `Maus` – Subklassen mit spezifischen Attributen
- `HauptMenue` – Benutzerinteraktion via Scanner
- `MainShop` – Einstiegspunkt

## Bekannte Einschränkungen
- Spezifische Attribute (z.B. Auflösung bei Monitor, Ergonomie bei Maus) können nicht bearbeitet werden

## Technologien
- Java
- Eclipse IDE
